你以后自己写 DFS，不要先想“递归好难”，你就按 **4 个问题** 写。

---

# DFS 四步法

## 第 1 步：我现在处理到哪里了？

这个就是 DFS 的参数。

比如这题：

```cpp
void dfs(int idx, ll cur)
```

意思是：

```text
idx：现在处理第几个质因子
cur：当前已经乘出来的因子
```

所以你以后写 DFS，先问：

> 我递归的时候，需要知道哪些信息？

常见参数有：

```cpp
dfs(pos)              // 当前处理到第 pos 个位置
dfs(pos, sum)         // 当前处理到 pos，当前和是 sum
dfs(pos, cur)         // 当前处理到 pos，当前结果是 cur
dfs(x, y)             // 当前在地图的 (x, y)
dfs(u)                // 当前在图上的 u 点
```

---

## 第 2 步：什么时候停止？

也就是递归出口。

比如这题：

```cpp
if (idx == factors.size()) {
    if (cur > X) {
        best = min(best, cur);
    }
    return;
}
```

意思是：

```text
所有质因子都选完了，cur 已经是一个完整因子
```

所以你以后写 DFS，第二步就问：

> 什么时候说明我已经构造完了？

常见出口：

```cpp
if (pos == n) return;
if (sum == target) return;
if (x 越界 || y 越界) return;
if (当前状态不合法) return;
```

---

## 第 3 步：当前位置有哪些选择？

这一步最重要。

比如这题当前质因子是 (p)，指数可以选：

[
0,1,2,\dots,2e
]

所以写：

```cpp
ll val = 1;

for (int i = 0; i <= 2 * e; i++) {
    dfs(idx + 1, cur * val);
    val *= p;
}
```

本质就是：

```text
枚举当前质因子的每一种指数选择
```

所以以后写 DFS，你问：

> 当前这一步，我能选什么？

比如：

### 子集问题

每个数有两种选择：

```text
选
不选
```

代码：

```cpp
dfs(pos + 1); // 不选
dfs(pos + 1); // 选
```

---

### 排列问题

当前位置可以填还没用过的数：

```cpp
for (int i = 0; i < n; i++) {
    if (!used[i]) {
        used[i] = true;
        dfs(pos + 1);
        used[i] = false;
    }
}
```

---

### 迷宫问题

当前位置可以往四个方向走：

```cpp
for (int k = 0; k < 4; k++) {
    int nx = x + dx[k];
    int ny = y + dy[k];
    dfs(nx, ny);
}
```

---

## 第 4 步：选完以后要不要恢复现场？

有些 DFS 要恢复，有些不用。

---

## 情况一：不用恢复现场

比如这题：

```cpp
dfs(idx + 1, cur * val);
```

因为 `cur * val` 是传给下一层的新值，原来的 `cur` 没有被修改。

所以不需要恢复。

这种叫：

```text
参数传递型 DFS
```

常见形式：

```cpp
dfs(pos + 1, sum + a[pos]);
dfs(pos + 1, sum);
```

不需要回溯。

---

## 情况二：需要恢复现场

比如排列问题：

```cpp
used[i] = true;
dfs(pos + 1);
used[i] = false;
```

因为 `used[i]` 是全局数组或者外部数组，你改了它。

递归回来之后，要改回去。

这种叫：

```text
修改现场型 DFS
```

常见形式：

```cpp
path.push_back(x);
dfs(...);
path.pop_back();
```

或者：

```cpp
vis[x][y] = true;
dfs(...);
vis[x][y] = false;
```

# DFS 通用模板

你以后可以先背这个：

```cpp
void dfs(当前状态) {
    if (到达终点) {
        更新答案;
        return;
    }

    for (枚举当前可以做的选择) {
        做选择;
        dfs(下一个状态);
        撤销选择;
    }
}
```

但是注意：如果你没有真的修改全局变量，就可以没有“撤销选择”。

---

# 套到这题就是

```cpp
void dfs(int idx, ll cur) {
    // 1. 终止条件
    if (idx == factors.size()) {
        if (cur > X) {
            best = min(best, cur);
        }
        return;
    }

    // 2. 当前处理的质因子
    ll p = factors[idx].first;
    int e = factors[idx].second;

    // 3. 枚举当前质因子的指数
    ll val = 1;
    for (int i = 0; i <= 2 * e; i++) {
        // 4. 当前选择 p^i，进入下一层
        dfs(idx + 1, cur * val);

        // 5. 准备下一种选择 p^(i+1)
        val *= p;
    }
}
```

这题不需要：

```cpp
恢复现场
```

因为 `cur * val` 没有改变原来的 `cur`。

# 你写 DFS 时就按这个顺序想

不要一上来就写代码，先写这四句话：

```text
1. dfs 参数表示什么？
2. 递归什么时候结束？
3. 当前这一步有哪些选择？
4. 做完选择后要不要恢复？
```

比如这题：

```text
1. dfs(idx, cur)：处理到第 idx 个质因子，当前因子是 cur
2. idx == factors.size() 时结束
3. 当前质因子的指数可以选 0 到 2e
4. 不需要恢复，因为没有修改全局状态
```

然后代码自然就出来了。

# 再给你一个最简单例子：枚举子集

比如数组：

```cpp
int a[3] = {1, 2, 3};
```

每个数都有两种选择：

```text
选它
不选它
```

代码：

```cpp
#include <bits/stdc++.h>
using namespace std;

int a[3] = {1, 2, 3};
vector<int> path;

void dfs(int pos) {
    if (pos == 3) {
        for (int x : path) {
            cout << x << ' ';
        }
        cout << '\n';
        return;
    }

    // 不选 a[pos]
    dfs(pos + 1);

    // 选 a[pos]
    path.push_back(a[pos]);
    dfs(pos + 1);
    path.pop_back();
}

int main() {
    dfs(0);
    return 0;
}
```

这里为什么需要：

```cpp
path.pop_back();
```

因为你修改了 `path`。

如果不恢复，后面的分支会被污染。

# 总结一句话

以后看到 DFS，就想：

> 我正在第几步？
> 什么时候结束？
> 当前有哪些选择？
> 选完要不要撤销？

这四个问题想清楚，DFS 就能写出来。
