可以。你以后遇到线性 DP，先别急着写代码，按下面这套流程
  想。

  1. 先问：这题是不是 DP

  DP 常见信号：

  求最大值 / 最小值 / 方案数 / 是否可行
  数据范围很大，暴力会重复计算
  答案可以由前面的较小状态推出来

  比如：

  爬楼梯：到第 n 阶的方法数
  斐波那契：第 n 项
  字符串拼接：S_n 由 S_{n-1}, S_{n-2} 得到
  打家劫舍：前 i 个房子能偷的最大值

  如果题目有明显的：

  第 i 个
  前 i 个
  到 i 为止
  从 1 到 n

  就很可能是线性 DP。

  2. 找状态：dp[i] 表示什么

  这是最重要的一步。

  小白先记一个万能句式：

  dp[i] 表示处理到第 i 个时的答案

  然后根据题目补完整：

  dp[i] 表示前 i 个数的最大和
  dp[i] 表示走到第 i 阶的方法数
  dp[i] 表示 S_i 的逆序对数量
  dp[i] 表示前 i 天能获得的最大利润

  你刚才那题就是：

  dp[i] 表示 S_i 中逆序对数量

  但只存 dp[i] 不够，所以还要额外存：

  zero[i]：S_i 里 0 的数量
  one[i]：S_i 里 1 的数量

  经验：如果转移时需要某些信息，就把它也设计成状态。

  3. 找转移：dp[i] 从哪里来

  问自己：

  第 i 个答案，和前面哪些答案有关？

  常见形式：

  dp[i] = dp[i - 1] + ...
  dp[i] = dp[i - 2] + ...
  dp[i] = max(dp[i - 1], dp[i - 2] + a[i])
  dp[i] = min(dp[i - 1], dp[i - 1] + cost)

  比如爬楼梯：

  到第 i 阶，可以从 i-1 走一步来，也可以从 i-2 走两步来

  所以：

  dp[i] = dp[i - 1] + dp[i - 2]

  比如打家劫舍：

  第 i 个房子偷不偷？
  不偷：dp[i - 1]
  偷：dp[i - 2] + a[i]

  所以：

  dp[i] = max(dp[i - 1], dp[i - 2] + a[i]);

  你那道字符串题：

  S_i = S_{i-2} + S_{i-1}

  逆序对来自三部分：

  S_{i-2} 内部
  S_{i-1} 内部
  左边的 1 和右边的 0

  所以：

  dp[i] = dp[i - 2] + dp[i - 1] + one[i - 2] * zero[i - 1];

  4. 找初始值

  转移公式不能凭空开始，必须有起点。

  比如：

  dp[1] = ...
  dp[2] = ...

  爬楼梯：

  dp[1] = 1;
  dp[2] = 2;

  斐波那契字符串：

  S1 = "0"
  S2 = "1"

  zero[1] = 1;
  one[1] = 0;
  dp[1] = 0;

  zero[2] = 0;
  one[2] = 1;
  dp[2] = 0;

  5. 确定遍历顺序

  线性 DP 一般从小到大：

  for (int i = 3; i <= n; i++) {
      ...
  }

  因为 dp[i] 依赖前面的状态。

  6. 看答案在哪里

  有的题答案是：

  dp[n]

  有的题答案是：

  max(dp[1], dp[2], ..., dp[n])

  比如“最大子段和”：

  dp[i] 表示以 i 结尾的最大子段和

  最后答案不是 dp[n]，而是所有 dp[i] 的最大值。

  小白固定模板

  以后遇到线性 DP，就按这 5 句话填：

  1. dp[i] 表示什么？
  2. dp[i] 从哪些状态转移来？
  3. 转移时多出来了什么贡献？
  4. 初始值是什么？
  5. 答案是 dp[n] 还是所有 dp 的最值？

  代码模板：

  dp[初始位置] = 初始值;

  for (int i = 起点; i <= n; i++) {
      dp[i] = 根据前面的 dp 推出来;
  }

  cout << dp[n];

  最重要的一句话：

  DP 不是背公式，而是想清楚“第 i 个答案怎么由前面的答案得
  到”。
