## 一、数位统计

**思路**：枚举范围内每个数，逐位拆分统计。

```cpp
int countDigit(int n, int d) {
    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        int x = i;
        while (x > 0) {
            if (x % 10 == d) cnt++;
            x /= 10;
        }
    }
    return cnt;
}
```

## 二、日期计算

**思路**：打表每月天数，写一个"日期+1"函数，从起始日期累加到目标。

```cpp
int days[13] = {0,31,28,31,30,31,30,31,31,30,31,30,31};

bool isLeap(int y) {
    return (y%4==0 && y%100!=0) || y%400==0;
}

// 给定年月日，返回是星期几（基姆拉尔森公式，0=周日）
int weekday(int y, int m, int d) {
    if (m < 3) { m += 12; y--; }
    return (d + 2*m + 3*(m+1)/5 + y + y/4 - y/100 + y/400 + 1) % 7;
}

// 日期推进一天
void nextDay(int &y, int &m, int &d) {
    int maxd = days[m] + (m==2 && isLeap(y) ? 1 : 0);
    if (++d > maxd) { d=1; if (++m > 12) { m=1; y++; } }
}
```

## 三、进制转换

**思路**：十进制转其他进制用短除法，其他进制转十进制按权展开。

```cpp
// 十进制转k进制，返回字符串
string toBase(int n, int k) {
    if (n == 0) return "0";
    string res = "";
    while (n > 0) {
        res += (char)('0' + n % k);  // 若k>10需处理字母
        n /= k;
    }
    reverse(res.begin(), res.end());
    return res;
}

// k进制字符串转十进制
long long fromBase(string s, int k) {
    long long res = 0;
    for (char c : s) {
        int d = isdigit(c) ? c-'0' : c-'A'+10;
        res = res * k + d;
    }
    return res;
}
```

## 四、找规律/数学推导

这类没有固定模板，但有固定的**解题流程**：

```
① 手算/打印前10-20项
② 观察差值、比值、奇偶规律
③ 猜公式，代入验证
④ 验证通过直接输出，不需要证明
```

```cpp
// 万能调试：先把前N项打出来看规律
for (int i = 1; i <= 30; i++) {
    // 模拟第i项的值
    cout << i << " -> " << f(i) << "\n";
}
```

常见规律类型：

- 等差/等比数列 → 直接套公式
- 周期规律 → 找到周期T，答案 = 第(n % T)项
- 斐波那契变形 → 写递推打表
- 取模规律 → 打表找循环节

## 五、组合计数（DFS枚举）

**思路**：数据范围小（一般n≤20），直接DFS枚举所有可能，统计满足条件的方案数。

```cpp
int n, ans = 0;
int a[25];

// 枚举选/不选每个元素的所有子集
void dfs(int idx, int cur_sum, int cur_cnt) {
    if (idx == n) {
        if (满足条件) ans++;
        return;
    }
    // 不选第idx个
    dfs(idx+1, cur_sum, cur_cnt);
    // 选第idx个
    dfs(idx+1, cur_sum + a[idx], cur_cnt+1);
}

// 枚举全排列
void dfs(int step, vector<int>& perm, bool used[]) {
    if (step == n) {
        // 检查这个排列是否满足条件
        return;-
    }
    for (int i = 0; i < n; i++) {
        if (!used[i]) {
            used[i] = true;
            perm.push_back(a[i]);
            dfs(step+1, perm, used);
            perm.pop_back();
            used[i] = false;
        }
    }
}
```

## 总结：考场做填空题的流程

```
看题 → 判断属于哪类 → 套对应模板 → 跑出答案 → 提交
         ↓
      判断不了？
         ↓
      数据范围小 → 暴力枚举
      数据范围大 → 手算前几项找规律
```

每类套路刷 3-5 道题就够形成肌肉记忆，不需要刷太多。重点是每道题做完之后，能说出"这道题属于哪类、用了什么模板"——这个意识比做题数量更重要。
