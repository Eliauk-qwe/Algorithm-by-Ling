一开始确实除了 0、1 以外全是 true。

  但这里的 true 不是说“它一定是质数”，而是说：

  目前还没有被证明是合数

  筛法的过程就是慢慢把合数改成 false。

  比如 N = 20。

  一开始：

  2~20 全是 true

  现在开始筛：

  ### i = 2

  is_prime[2] == true

  说明 2 还没有被前面的数筛掉，所以 2 是质数。

  然后把 2 的倍数标记成 false：

  4, 6, 8, 10, 12, 14, 16, 18, 20 = false

  ### i = 3

  is_prime[3] == true

  说明 3 还没被筛掉，所以 3 是质数。

  然后把 3 的倍数标记成 false：

  9, 12, 15, 18 = false

  ### i = 4

  is_prime[4] == false

  说明 4 已经被 2 筛掉了，它不是质数，所以跳过。

  ### i = 5

  如果继续看：

  is_prime[5] == true

  说明 5 没被任何小于它的质数整除，所以它是质数。

  所以这句：

  if (is_prime[i])

  意思是：

  如果 i 到现在还没被筛掉，那 i 就是质数

  不是一开始就知道谁是质数，而是通过不断筛合数，剩下的
  true 就是质数。

  简单理解：

  vector<bool> is_prime(N + 1, true);

  相当于:

  先默认大家都是好人
  发现谁是合数，就标记 false
  最后没被标记的人，就是质数
