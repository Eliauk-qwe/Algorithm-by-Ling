## 一、一维前缀和

### 用途
快速查询区间和 `[L, R]`

### 模板
```cpp
// ========== 初始化前缀和 ==========
// 方式1：直接输入时递推（推荐）
for (int i = 1; i <= n; i++) {
    cin >> a[i];
    sum[i] = sum[i - 1] + a[i];
}

// 方式2：先存数组，再统一求
for (int i = 1; i <= n; i++) {
    sum[i] = sum[i - 1] + a[i];
}

// ========== 查询区间和 [L, R] ==========
int query = sum[R] - sum[L - 1];
```

### 核心公式

| 操作 | 公式 |
|------|------|
| 构造前缀和 | `sum[i] = sum[i-1] + a[i]` |
| 查询区间和 | `sum[R] - sum[L-1]` |

## 二、一维差分

### 用途
多次对区间 `[L, R]` 统一加 `val`，最后求最终数组

### 模板
```cpp
// ========== 初始化差分（初始全0可跳过） ==========
// 如果初始数组 a 非零，先求差分
for (int i = 1; i <= n; i++) {
    diff[i] = a[i] - a[i - 1];
}

// ========== 区间修改 [L, R] += val ==========
diff[L] += val;
diff[R + 1] -= val;

// ========== 前缀和还原 ==========
for (int i = 1; i <= n; i++) {
    diff[i] += diff[i - 1];
    // 此时 diff[i] 就是最终数组的值
}
```

### 核心公式

| 操作 | 公式 |
|------|------|
| 构造差分（已知 a） | `diff[i] = a[i] - a[i-1]` |
| 区间加 | `diff[L] += val` <br> `diff[R+1] -= val` |
| 还原 | `diff[i] += diff[i-1]` |

## 三、二维前缀和

### 用途
快速查询矩形区域和 `(x1,y1)` 到 `(x2,y2)`

### 模板
```cpp
// ========== 初始化前缀和 ==========
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        cin >> a[i][j];
        sum[i][j] = a[i][j] 
                  + sum[i - 1][j] 
                  + sum[i][j - 1] 
                  - sum[i - 1][j - 1];
    }
}

// ========== 查询矩形和 (x1,y1) ~ (x2,y2) ==========
int query = sum[x2][y2] 
          - sum[x1 - 1][y2] 
          - sum[x2][y1 - 1] 
          + sum[x1 - 1][y1 - 1];
```

### 核心公式

| 操作 | 公式 |
|------|------|
| 构造前缀和 | `sum[i][j] = a[i][j] + sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1]` |
| 查询矩形和 | `sum[x2][y2] - sum[x1-1][y2] - sum[x2][y1-1] + sum[x1-1][y1-1]` |

### 图解查询公式

```
要求蓝色矩形区域的和：

     y1-1   y1     y2
x1-1  A ┌───┬───────┐
         │   │       │
x1       ├───┼───────┤
         │   │ Blue  │
x2       └───┴───────┘

Blue = 右下大矩形(sum[x2][y2])
     - 左边白色(sum[x2][y1-1])
     - 上边白色(sum[x1-1][y2])
     + 左上A(sum[x1-1][y1-1])  ← 多减了一次，补回来
```

## 四、二维差分

### 用途
多次对矩形区域 `(x1,y1)` 到 `(x2,y2)` 统一加 `val`，最后求最终矩阵

### 模板
```cpp
const int N = 1005;
int diff[N][N];  // 全局数组，自动初始化为 0

//  !!!!!  a为二维前缀和数组

// ========== 初始化差分（初始全0可跳过） ==========
// 如果初始数组 a 非零，先求差分
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        diff[i][j] = a[i][j] - a[i-1][j] - a[i][j-1] + a[i-1][j-1];
    }
}

// ========== 矩形修改 (x1,y1) ~ (x2,y2) += val ==========
diff[x1][y1] += val;
diff[x2 + 1][y1] -= val;
diff[x1][y2 + 1] -= val;
diff[x2 + 1][y2 + 1] += val;

// ========== 前缀和还原 ==========
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        diff[i][j] += diff[i-1][j] + diff[i][j-1] - diff[i-1][j-1];
        // 此时 diff[i][j] 就是最终矩阵的值
    }
}
```

### 核心公式

| 操作 | 公式 |
|------|------|
| 构造差分（已知 a） | `diff[i][j] = a[i][j] - a[i-1][j] - a[i][j-1] + a[i-1][j-1]` |
| 矩形加 | `diff[x1][y1] += val` <br> `diff[x2+1][y1] -= val` <br> `diff[x1][y2+1] -= val` <br> `diff[x2+1][y2+1] += val` |
| 还原 | `diff[i][j] += diff[i-1][j] + diff[i][j-1] - diff[i-1][j-1]` |

### 图解修改公式（四个角）

```
矩形区域 (x1,y1) ~ (x2,y2) +val：

        y1       y2  y2+1
x1    ┌──┬───────┬──┐
      │  │       │  │
      │  │ 矩形  │  │
x2    ├──┼───────┼──┤
      │  │       │  │
x2+1  └──┴───────┴──┘

(x1, y1)       → +val   起点，影响从这里开始
(x2+1, y1)     → -val   行影响停止
(x1, y2+1)     → -val   列影响停止
(x2+1, y2+1)   → +val   多减的补回来
```

## 五、总结对比表

| | 前缀和 | 差分 |
|------|--------|------|
| **方向** | a → sum（累积） | a → diff（反推变化） |
| **用途** | 快速查询区间/矩形和 | 快速进行区间/矩形修改 |
| **核心思想** | 空间换时间，O(1) 查询 | 只在边界打标记，最后统一还原 |
| **还原方式** | 直接查公式 | 对差分数组求前缀和 |

| 维度 | 前缀和构造 | 前缀和查询 | 差分构造 | 差分区修 | 差分还原 |
|------|-----------|-----------|---------|---------|---------|
| 一维 | `sum[i] = sum[i-1] + a[i]` | `sum[R] - sum[L-1]` | `diff[i] = a[i] - a[i-1]` | `diff[L]+=v, diff[R+1]-=v` | `diff[i] += diff[i-1]` |
| 二维 | `sum[i][j] = a[i][j] + sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1]` | `sum[x2][y2] - sum[x1-1][y2] - sum[x2][y1-1] + sum[x1-1][y1-1]` | `diff[i][j] = a[i][j] - a[i-1][j] - a[i][j-1] + a[i-1][j-1]` | 四个角 ±v | `diff[i][j] += diff[i-1][j] + diff[i][j-1] - diff[i-1][j-1]` |

## 六、记忆口诀

```
一维：
  前缀和：后面加前面
  差  分：自己减前面
  区修改：头加尾减
  还  原：自己加前面

二维：
  前缀和：自己加上左减左上
  差  分：自己减上减左加左上
  区修改：左上加减，右上减，左下减，右下加
  还  原：自己加上左减左上
```

注意到规律了吗？**前缀和和差分的公式互为逆运算，符号刚好相反。**
